
# SEO Checklist - Studio Greisy

## Pasos importantes después del deploy

1. Subir nuevamente el proyecto a GitHub
2. Verificar que Vercel haga el deploy automáticamente
3. Registrar el sitio en Google Search Console:
   https://search.google.com/search-console

4. Enviar sitemap:
   https://studio-greisy-v.vercel.app/sitemap.xml

5. Solicitar indexación manual en Search Console

## Recomendación importante
Comprar un dominio propio:
- studiogreisy.com
- studiogreisy.co

Esto mejora mucho el posicionamiento SEO.
